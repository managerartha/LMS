# LMS Artha Safety Indonesia

Learning Management System untuk peserta pelatihan Artha Safety Indonesia:
absensi 2 sesi/hari (foto + timestamp + tanda tangan), rundown, materi,
dokumentasi kegiatan, dan laporan kegiatan otomatis dalam bentuk PDF.

Teknologi: HTML + Google Apps Script, data di Google Spreadsheet, file di Google Drive.
