# LMS Artha Safety Indonesia

Learning Management System untuk peserta pelatihan Artha Safety Indonesia:
absensi 2 sesi/hari (foto + timestamp + tanda tangan + lokasi GPS), rundown, materi,
dokumentasi kegiatan, dan laporan kegiatan otomatis dalam bentuk PDF.

Teknologi: tampilan HTML/CSS/JS statis di cPanel (`lms.arthasafetyindonesia.com`), API Google Apps Script, data di Google Spreadsheet, file di Google Drive.

| [docs/PANDUAN-SETUP.md](docs/PANDUAN-SETUP.md) | Cara memasang di akun Google & membagikan link |
