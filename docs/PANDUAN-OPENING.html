🎬 Panduan Opening Pelatihan

Halaman upacara pembukaan pelatihan PT Artha Safety Indonesia, pengganti PowerPoint. Dibuka di browser (Chrome/Edge) lewat tombol di LMS, tanpa instal aplikasi apa pun.

1. Memasang di Hostinger (sekali saja)

Pasang setelah jam 17.00 seperti biasa. Data LMS tidak berubah; hanya ada 1 kolom baru (opsional) di data batch.

b. Modul Opening (folder baru)

  1. Di File Manager Hostinger, buka public_html, buat folder baru bernama opening.
  2. Upload ke public_html/opening/: index.html (milik opening), opening.css, opening.js, config.json.
  3. Di dalam opening, buat folder assets, lalu upload: logo.png, petugas-kiri.webp, petugas-kanan.webp, musik-latar.mp3.
  4. Di dalam assets, buat folder video. Video diupload ke sini (lihat bagian 2).

2. Video

Video tidak diputar dari Google Drive. Upload file video langsung ke hosting, folder public_html/opening/assets/video/, dengan nama persis:

Nama fileIsi
safety-induction.mp4Safety Induction (hanya tampil untuk kelas online)
indonesia-raya.mp4Lagu Indonesia Raya
sambutan-direktur.mp4Sambutan Direktur
  • Format: MP4 (H.264 + AAC) — bisa diputar di semua browser.
  • Ukuran disarankan: 720p, sekitar 20–60 MB per video agar cepat dimuat. Video besar bisa dikecilkan gratis dengan aplikasi HandBrake: buka video → pilih preset Fast 720p30 → Format MP4 → Start Encode.
  • Upload file besar: lewat File Manager Hostinger (tombol Upload). Jika gagal karena ukuran, pakai aplikasi FileZilla (FTP) dengan akun FTP dari hPanel.
  • Selama video belum diupload, bingkai video menampilkan pesan "File video … belum diupload ke hosting" (bukan layar kosong).

3. Mengganti video, musik, atau kontak (config.json)

Buka public_html/opening/config.json di File Manager (klik kanan → Edit). Ubah teks di antara tanda kutip saja, lalu Simpan.

"video": {
  "safety_induction": "assets/video/safety-induction.mp4",
  "indonesia_raya": "assets/video/indonesia-raya.mp4",
  "sambutan_direktur": "https://youtu.be/XXXXXXXXXXX"     ← boleh link YouTube (unlisted)
},
"musik": {
  "file": "assets/musik-latar.mp3",                        ← ganti file musik (MP3)
  "volume": 0.35,                                          ← volume normal (0 – 1)
  "volume_pelan": 0.12,                                    ← volume mode "Pelan"
  "persen_saat_safety_offline": 0.2,                       ← 20% saat Safety Induction offline
  "lama_fade_detik": 1.5
}
  • Ganti video: paling mudah upload file baru dengan nama yang sama (menimpa file lama). Atau tulis nama file / link YouTube lain di config.
  • Ganti musik: upload MP3 baru ke assets/, lalu ubah "file". Musik bawaan adalah instrumental buatan sendiri (bebas royalti).
  • Jangan menghapus tanda kutip ", titik dua :, atau koma ,. Jika config rusak, halaman tetap jalan dengan pengaturan bawaan.
  • Nama perusahaan in-house diisi Admin di LMS: menu Batch → Ubah → Perusahaan (in-house).

4. Cara PIC memakai saat acara

  1. Sambungkan laptop ke proyektor & speaker, pastikan internet tersambung.
  2. Login LMS sebagai PIC/Admin → Dashboard → kartu 🎬 Opening pelatihan → Buka Opening (atau menu Batch → 🎬 Buka Opening). Halaman terbuka di tab baru.
  3. Tekan F untuk layar penuh. Tampilan Layar Siaga bisa dibiarkan selama peserta masuk.
  4. Saat acara dimulai, klik MULAI (atau tekan tombol clicker). Musik latar mulai berbunyi.
  5. Pindah slide dengan clicker / panah. Pada slide video, klik ▶ saat siap — video tampil layar penuh, musik mengecil lalu berhenti. Selesai video, layar kembali ke slide yang sama dan musik naik lagi. Video tidak pernah berjalan sendiri, jadi PIC bebas berbicara dulu.
  6. Kelas offline: slide Safety Induction tanpa video (disampaikan pihak tempat pelatihan), musik otomatis dikecilkan.
Urutan: Layar Siaga → Pembukaan → Safety Induction → Indonesia Raya → Sambutan Direktur → Penutup. Langkah di bar bawah juga bisa diklik untuk langsung lompat.

Latihan tanpa LMS

Untuk gladi/latihan: …/opening/?demo=online, ?demo=offline, atau ?demo=inhouse (data contoh, tanpa login).

5. Jika ada masalah

TampilanPenyebab & solusi
"Silakan login ke LMS dulu"Login LMS sebagai PIC/Admin di browser yang sama, lalu klik Buka Opening lagi.
"Link opening tidak lengkap"Buka dari tombol di LMS, bukan mengetik alamat manual.
"File video … belum diupload"Upload video dengan nama yang benar ke opening/assets/video/.
"Video tidak dapat dimuat, periksa koneksi internet"Periksa internet, klik ↻ Coba muat lagi. Saran: buka halaman opening 5–10 menit sebelum acara agar video sempat dimuat.
Musik tidak bunyiPastikan sudah klik MULAI, tombol musik tidak "Mati", dan volume laptop/speaker menyala. Tulisan "Musik ✕" = file musik tidak ditemukan.
